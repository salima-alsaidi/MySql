School Registry Console

A working desk for the school directory service at localhost:8080. Add entries, review the roll, and correct or retire a record.

Add a school

POST /school/add?schoolName=&location=

Full roll

GET /school/getAll

Look up by ID

GET /school/getById?id=

Amend a record

PUT /school/update?id=&name=&location=

Retire a record

DELETE /school/deleteById?id=

This calls the delete endpoint directly — there is no undo from here.
